# Parent iPad — Naomi’s Luce

Short how-to for Christina / Jarrod. Use on Naomi’s iPad (Safari).

## Open Luce

1. Open **https://luce-naomi.pages.dev**
2. Enter the family password (**from Jarrod / Luce chat** — not written here)
3. Tap **Open Luce**

## Optional: Add to Home Screen

In Safari: **Share → Add to Home Screen**. Full-screen Luce icon, less browser chrome.

## What you’ll see

- **Dual captions** — Naomi’s words and Luce’s lines (both parents follow on screen)
- Soft face to talk, exactly two big picture choices
- No kid Help button

## Parent corner

Top-right tiny mark (·). **Long-press** — opens the parent panel.

- **Visual + vibrate only** — no sound (Deaf-friendly)
- Large captions, session status, optional Add to Home Screen tip
- **Hang up** — ends the sitting (bye / bye-bye from Naomi also ends it)

## Hang up / bye

Naomi can say bye, bye-bye, goodbye, see you later, night-night, etc. Or use **Hang up** in the parent corner.
